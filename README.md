# World of Warcraft: Forever — Cuenta Regresiva Fandom

Sitio web tematico de cuenta regresiva para World of Warcraft: Forever, disenado por y para la comunidad de Azeroth.

> **Aviso Fandom:**  
> Este es un proyecto no oficial sin fines de lucro desarrollado por fans. No esta afiliado, respaldado ni asociado con Blizzard Entertainment ni Microsoft. World of Warcraft y sus marcas comerciales asociadas son propiedad de Blizzard Entertainment.

---

## Caracteristicas

- **Tablon de Misiones Inmersivo**: Estilos visuales tematicos inspirados en el Tablon de Ordenes de Orgrimmar y la Llamada del Heroe de Ventormenta.
- **Selector de Facciones**: Modos intercambiables para Horda, Alianza y Titanes con fondos atmosfericos e iluminacion reactiva.
- **Contador en Tiempo Real**: Conteo regresivo de alta precision (Dias, Horas, Minutos, Segundos y Milisegundos).
- **Banda Sonora Integrada**: Reproductor de audio HUD en bucle continuo (*Two Steps From Hell — Victory*).
- **Diseno Adaptable**: Optimizado para dispositivos moviles, tabletas y computadoras de escritorio.

---

## Tecnologias

- HTML5 semantico
- CSS3 puro (diseno responsivo, filtros y animaciones)
- JavaScript Vanilla (sin dependencias externas)
- YouTube IFrame API
